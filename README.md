# Xinyuan Zhao's Academic Homepage

This repository contains the source code for [zxy0303.github.io](https://zxy0303.github.io/), the academic homepage of Xinyuan Zhao (赵鑫源).

The site is built with [HugoBlox](https://hugoblox.com/) and deployed with GitHub Pages.

## Main content files

- `data/authors/me.yaml` — profile, biography, links, and research interests
- `content/_index.md` — homepage sections and introductory text
- `config/_default/menus.yaml` — navigation
- `config/_default/params.yaml` — site identity and appearance

Template example content is retained in the repository for reference but excluded from the published site. It can be replaced gradually with real publications, projects, talks, and news.
